# AgentTalk

카카오톡 스타일의 단체 대화방에서 여러 LLM 에이전트가 서로 대화하는 로컬 웹 앱입니다.
에이전트마다 성격·말투·비밀을 주고, 프로바이더와 모델도 따로 고를 수 있습니다.
마피아 게임처럼 프로그램이 규칙을 진행하는 **방 모드**도 지원합니다.

지원 프로바이더: OpenAI, Anthropic, Google Gemini, xAI, Mistral, Groq, DeepSeek, OpenRouter, Ollama, OpenAI 호환 서버

## 빠른 시작

Node.js 22.13 이상과 Yarn 1이 필요합니다.

```bash
yarn install
yarn dev        # API 서버(127.0.0.1:8787) + Vite(5173)
```

브라우저에서 **설정 → 프로바이더 프로필 → 추가**를 누르고 API 키를 넣습니다. 저장하기 전에 **연결 테스트**로 확인할 수 있습니다.

프로덕션 빌드:

```bash
yarn build
yarn start      # 127.0.0.1:8787 에서 빌드된 앱과 API 제공
```

## 주요 기능

### 대화

- **진행 모델이 마이크만 건넵니다.** 발언 순서와 횟수는 정해져 있지 않습니다. 진행 모델은 매 차례 다음 화자 후보, 상황 메모, 텀, 멈출지를 정합니다. 무엇을 말할지는 에이전트가 자기 캐릭터와 비밀을 바탕으로 정합니다.
- **내 말이 우선입니다.** 에이전트끼리 대화하는 중에 말하면 진행 중인 생성을 끊고 내 말에 다시 반응합니다. 방마다 **자동 반응 / 부르면 답함**을 고를 수 있습니다.
- **부르기와 귓속말:** `@이름`은 공개 호출이고, 메시지 맨 앞의 `@@이름`은 그 사람만 보는 귓속말입니다. 에이전트끼리도 귓속말을 주고받습니다.
- **패스:** 끼어들 이유가 없는 에이전트는 `[패스]`합니다. 고른 사람들이 연달아 패스하면 대화가 잦아든 것으로 보고 멈춥니다.
- **웹 검색:** 검색 도구를 지원하는 모델(OpenAI, Anthropic, Gemini, xAI)의 에이전트는 필요할 때 스스로 검색합니다.
- **안전장치:** 사람의 입력 없이 이어지는 자동 발언은 최대 30회까지입니다.

### 에이전트와 방 설정

- **AI로 다듬기:** 짧게 쓴 에이전트 설명이나 대화 주제를 자세하게 다시 써 줍니다.
- **에이전트 자동 생성:** 주제와 현재 멤버를 보고, 겹치지 않는 관점과 말투를 가진 에이전트를 최대 30명까지 만듭니다.
- **소개 공개:** 다른 멤버의 소개 첫 문장을 공개할지 방마다 정합니다.
- **프리셋:** 대화 기록을 뺀 방 설정과 멤버를 저장해 두고 새 방을 만들 때 씁니다.
- **모델 우선순위:** 에이전트 → 방 → 프로필 기본값 순으로 적용합니다. Effort(추론 강도)도 같은 순서로 덮어쓸 수 있습니다.

### 이미지 (OpenAI)

- **표정:** 에이전트 얼굴을 만들고, 발언마다 고른 표정에 맞춰 같은 얼굴의 새 표정을 만듭니다.
- **사진 보내기:** 허용한 에이전트는 대화 중에 직접 그림이나 사진을 만들어 보냅니다.

### 방 메모

방장에게만 보이는 요약 메모를 채팅방 옆에 띄웁니다. 메모는 참가자와 진행 모델에게 전달하지 않습니다. 비공개 정보를 다루기 때문에 승인된 OpenAI 공식 API 프로필만 쓸 수 있습니다.

### 🕵️ 마피아 게임 모드

이 모드에서는 자기소개 순서, 역할 배정, 밤 행동, 투표 집계, 처형, 승패를 **프로그램이** 정합니다. 진행 모델은 낮 토론의 다음 화자만 고르며, 역할 정보는 받지 않습니다.

| 참여 방식   | 설명                                                                              |
| ----------- | --------------------------------------------------------------------------------- |
| 👀 관전     | 에이전트끼리 끝까지 진행합니다. 모든 역할과 밤 대화가 보입니다.                   |
| 🎙️ 사회     | 내가 사회자로 단계마다 진행하고 투표를 시작합니다.                                |
| 🙋 플레이어 | 나도 역할을 받아 참가합니다. 살아 있는 동안은 내 역할로 알 수 있는 것만 보입니다. |

- 역할은 무작위로 배분하거나 직접 지정합니다.
- 마피아 수, 의사·경찰 포함 여부, 낮 토론 길이를 정할 수 있습니다.
- 게임이 끝나면 연출 모델이 상황 설정에 맞는 엔딩 장면을 만듭니다.

## 구조

```
src/            React 19 + jotai + react-query + Tailwind 4 프론트엔드
  modes/        방 모드 (일반 대화, 마피아 게임)
server/         Hono 로컬 API 서버. Vercel AI SDK로 모든 프로바이더를 같은 API로 호출
  modes/        모드별 서버 AI 작업
shared/         서버와 클라이언트가 함께 쓰는 스키마(zod)와 프로바이더 카탈로그
```

### 새 방 모드 추가하기

공통 코드(대화 엔진, 프롬프트, 화면)는 모드를 직접 알지 않습니다. 아래 세 함수로만 모드에 접근합니다.

- `modeOf(room)`: 규칙
- `engineOf(room)`: 대화 엔진 훅
- `modeUiOf(mode)`: 화면

1. `src/types/chat.ts`의 `RoomMode`에 id를 더합니다.
    - 방 설정이 있으면 `ModeSettings`에 더합니다. 값은 `room[id]`에 저장됩니다.
    - 진행 상태가 있으면 `ModeStates`에 더합니다. 값은 `room.modeState[id]`에 저장됩니다.
2. `src/modes/<id>/`에 규칙(`defineMode`), 엔진(`ModeEngine`), 화면(`ModeUi`)을 만듭니다.
3. `modes/index.ts`, `modes/engines.ts`, `modes/ui.ts`에 등록합니다. 하나라도 빠뜨리면 컴파일 오류가 납니다.
4. 서버 AI 작업이 필요하면 `server/modes/<id>/`에 `defineModeAction`으로 만들어 `server/modes/index.ts`에 등록합니다. 클라이언트에서는 `runModeAction(id, 작업 이름, 요청)`으로 부릅니다. 모든 작업은 `POST /api/modes/:mode/:action` 하나로 처리합니다.

모드 코드가 앱 상태와 서버에 닿는 통로는 `modes/runtime.ts` 하나입니다. 화면에서 대화 엔진을 멈추거나 다시 시작할 때는 `modes/controls.ts`를 씁니다. 다른 경로로 import하면 ESLint가 막습니다. 자세한 계약은 `src/modes/core.ts`에 있습니다.

## 데이터 저장

- 채팅방, 메시지, 방 메모, 프리셋은 서버의 SQLite 파일(`data/agenttalk.db`)에 저장합니다. Node 내장 `node:sqlite`를 씁니다.
- 브라우저 localStorage에는 화면 설정(내 이름, 지역, 모델 선택 등)만 남습니다.
- 브라우저는 바뀐 부분만 묶어서 서버에 저장합니다. 이전 버전 형식의 데이터는 불러올 때 자동으로 새 형식으로 바꿉니다.
- 생성한 이미지는 `data/images/`에 저장합니다.

## 보안

- **API 키 암호화:** 프로필은 `data/profiles.json`에 저장하고, API 키는 AES-256-GCM으로 암호화합니다. 프로필 ID를 AAD로 묶어 두어, 암호문을 다른 프로필에 옮기면 복호화되지 않습니다.
- **마스터 키:** 기본은 자동 생성되는 `data/secret.key`입니다. 환경변수 `AGENTTALK_SECRET`(16자 이상)을 주면 키 파일 없이 그 값으로 키를 만듭니다.
- **키는 브라우저로 돌아가지 않습니다.** 화면에는 마지막 4자리만 보이고, LLM 호출은 서버가 대신 합니다.
- **로컬 전용 서버:** 서버는 `127.0.0.1`에만 바인딩합니다. `Host` 헤더가 localhost가 아니면 요청을 거부해 DNS 리바인딩을 막습니다.
- **파일 권한:** `data/`는 `0700`, 그 안의 파일은 `0600` 권한으로 만듭니다. 이 디렉터리는 `.gitignore`에 들어 있습니다.

> `profiles.json`과 `secret.key`가 같은 디스크에 있으면, 디스크를 가져간 사람은 키를 복호화할 수 있습니다.
> 더 강하게 보호하려면 `AGENTTALK_SECRET`을 쓰고 `secret.key`를 두지 마세요.
> 마스터 키를 잃어버리면 저장된 API 키는 복구할 수 없습니다.

| 환경변수             | 기본값                  | 설명                                 |
| -------------------- | ----------------------- | ------------------------------------ |
| `PORT`               | `8787`                  | API 서버 포트                        |
| `HOST`               | `127.0.0.1`             | 바인딩 주소                          |
| `AGENTTALK_DATA_DIR` | `./data`                | 데이터 저장 위치                     |
| `AGENTTALK_SECRET`   | (없음)                  | 마스터 키 패스프레이즈               |
| `AGENTTALK_API`      | `http://127.0.0.1:8787` | (개발) Vite가 `/api`를 프록시할 대상 |
